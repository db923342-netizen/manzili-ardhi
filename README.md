# Manzili & Ardhi

أنشئ منصة عقارية احترافية باسم "منزلي وأرضي" (Manzili & Ardhi) مخصصة للجزائر، باللغة العربية مع دعم RTL، وتصميم متجاوب مع الهواتف والكمبيوتر.



استخدم React وTypeScript وTailwind CSS.

أنشئ واجهة رئيسية حديثة بألوان الأخضر الداكن والأبيض والذهبي.



تتضمن المنصة:

- الصفحة الرئيسية والبحث حسب الولاية والبلدية ونوع العقار.

- التسجيل وتسجيل الدخول بالبريد الإلكتروني.

- نشر العقارات للإيجار.

- نشر طلبات البحث عن عقارات للإيجار.

- صفحات تفاصيل العقارات والطلبات.

- صفحة الملف الشخصي.

- لوحة تحكم للمدير لإدارة المستخدمين والعقارات والطلبات والصفقات.

- نظام رسوم واضح بالدينار الجزائري.

- إخفاء أرقام الهواتف عن الطرف الآخر حتى إتمام الصفقة وموافقة المدير.



ابدأ ببناء الواجهات والصفحات والتنقل بينها، واجعل التصميم عربيًا بالكامل ومتوافقًا مع الهاتف.



لا تنشئ قاعدة بيانات جديدة ولا تعدّل قاعدة Supabase الحالية في هذه المرحلة. لا تستخدم مفاتيح سرية في الواجهة الأمامية.
